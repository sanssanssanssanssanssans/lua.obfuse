# 기여 가이드

- Lua.obfuse에 관심 가져 주셔서 감사합니다! 

## 기여 방법

- 1. Issue를 열어서 먼저 제안하거나 버그를 보고해주시고, 가능한 재현 단게와 운영체제를 포함해야합니다.
- 2. Fork 후에 Branch를 생성합니다.
- 3. 변경후 tests/에 테스트를 실행하고 로컬에서 실행해주세요.
- 4. PR을 생성해서 변경 내용을 설명 후, 테스트 방법, 관련 이슈 번호를 포함해주세요.

## 코드 스타일

- Python은 PEP8 (가능하면 ruff나 black으로 format)을 준수해야합니다.
- 핵심 로직은 core/에, 무상태 헬퍼는 utils/에 두셔야합니다.

## 검토

- PR은 코드 리뷰 후, CI 통과후에 Merge됩니다.
- 큰 변경은 ( 예시로 난독화 알고리즘을 변경하는 건 )에 대해서는, 사전에 이슈를 생성하는것을 권장합니다.

## 문제 보고

문제를 보고하기 위해서는 다음을 포함하셔야 합니다.
- 재현 단계 
- 오류 로그
- 사용한 명령어
- Python/Lua/OS 버전

## 행동 강령

- **모든 기여자는 상호 존중**해야 합니다. 혐오적인 발언, 차V별적인 표현, 인신 공격은 불허됩니다.
